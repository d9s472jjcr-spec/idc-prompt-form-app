# IDC Prompt Form — Public Release

個人利用向けCanonical Prompt FormのGitHub Pages公開成果物です。

- 公開URL: https://d9s472jjcr-spec.github.io/idc-prompt-form-app/
- 対象モード: Canonical生成
- 対応端末の第一優先: iPhone 16
- 配信方式: GitHub Pagesによる静的サイト
- 画面構成: 4ページ（基本・性格・能力／髪・顔・肌・メイク／体型・衣装・小物／出力）
- 操作ドック: BACK／RANDOM／NEXT
- 選択移動: 単一選択・色・モードはリストを閉じて次項目へ進み、同じ値の再選択にも対応。複数選択は上限到達時に進む
- 初期値: 年齢20、身長158cm、B81cm、W57cm、H82cm、能力各30、アイウェア・アクセサリーは「なし」
- 体型派生値: 体重・アンダーバスト・Cupを読み取り専用で自動計算し、Snapshotと三面Promptへ反映。採用済みv1.1では、選択Wと身長基準Wの差の20%をUBへ反映
- 相関解決: PFM-029採用版として正式41件を決定順で評価し、Canonical対象29件の適用数と任意未実行8件を出力プレビューへ表示
- 自動値具体化: PFM-030採用版として、seed固定・項目別stream・正式な正の重みにより自動値を具体化し、完全な決定証跡をSnapshotへ保存
- 最終矛盾検査: PFM-031採用版として、成果物生成直前に13件を横断検査し、矛盾時はSnapshotとPromptを生成しない
- 解決過程ログ: PFM-032採用版として、操作・自動決定・41相関・上限・最終検査を連番でSnapshotへ保存し、概要と詳細を表示
- 項目別文章化: PFM-033採用版として、正式出力語・正式色名・数値と単位を項目名との関係が明確な日本語一文へ変換
- 語順・優先順位: PFM-034採用版として、正式ブロック順と各ブロック内の優先度順を適用し、Snapshotへ決定的な順序証跡を保存
- 重複表現統合: PFM-035確認待ち候補として、同一ブロックの完全一致文だけを統合し、統合元をSnapshotへ保存
- 三面コンパイラ: PFM-036〜041確認待ち候補として、人物固定・衣装装飾・整合禁止ブロックと正面・3/4・背面テンプレートを正式仕様へ監査済み
- 衣装補助: アクセント素材・装飾は「任意（省略可）」と表示し、未選択なら省略。柄は「無地」を初期値として明示
- 詳細設定: 通常項目と異なる背景色と左アクセントで識別
- イメージカラー: 1ページ目の基本セクション
- 無効値処理: 正式action（解除・初期値へ変更・保持）に従い、元入力を監査値として保ったままPrompt用の解決済み値から無効部分を除外
- 操作通知: 条件変更で値が無効になった場合、処理件数・項目・actionを画面に表示
- 複数選択上限: Masterの上限を常時表示し、到達後は追加を止めて選択済み項目の解除で復旧。条件外の保持値は元入力監査へ残し、現在件数には含めない

## プライバシー

入力値はブラウザ内だけで処理し、サーバーへ送信・自動保存しません。

この公開リポジトリには、ブラウザで動作する配布用JavaScriptと正式派生Masterが含まれます。これらは公開情報として扱います。実在人物や個別人物の入力値は含みません。
