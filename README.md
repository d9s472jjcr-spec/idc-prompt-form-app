# IDC Prompt Form — Public Release

個人利用向けCanonical Prompt FormのGitHub Pages公開成果物です。

- 公開URL: https://d9s472jjcr-spec.github.io/idc-prompt-form-app/
- 対象モード: Canonical生成
- 対応端末の第一優先: iPhone 16
- 配信方式: GitHub Pagesによる静的サイト
- 画面構成: 4ページ（基本・性格・能力／髪・顔・肌・メイク／体型・衣装・小物／出力）
- 操作ドック: BACK／RANDOM／NEXT
- 選択移動: 単一選択・色・モードはリストを閉じて次項目へ進み、同じ値の再選択にも対応。複数選択は上限到達時に進む
- 初期値: 年齢20、身長157.4cm、B81.1cm、W56.2cm、H81.5cm、能力各30、アイウェア・アクセサリーは「なし」
- 衣装補助: アクセント素材・装飾は「任意（省略可）」と表示し、未選択なら省略。柄は「無地」を初期値として明示
- 詳細設定: 通常項目と異なる背景色と左アクセントで識別
- イメージカラー: 1ページ目の基本セクション
- 無効値処理: 正式action（解除・初期値へ変更・保持）に従い、元入力を監査値として保ったままPrompt用の解決済み値から無効部分を除外
- 操作通知: 条件変更で値が無効になった場合、処理件数・項目・actionを画面に表示

## プライバシー

入力値はブラウザ内だけで処理し、サーバーへ送信・自動保存しません。

この公開リポジトリには、ブラウザで動作する配布用JavaScriptと正式派生Masterが含まれます。これらは公開情報として扱います。実在人物や個別人物の入力値は含みません。
